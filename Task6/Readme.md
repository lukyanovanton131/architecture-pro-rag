Обновление инлдекса выполняется тем же скриптом, что и в задании два. 
В папку csv скидываются новые документы и скрипт пересоздает индекс.
Время пересоздания не критичное, 10 мин.
Скрипт обновления update.sh запускается через cron каждый день в 3 часа ночи.
Нужно сделать скрипт запускаемым
```bash
chmod +x update.sh
```

Отредактировать crontab
```text
# Ежедневное обновление базы знаний в 3:00
0 3 * * * /bin/bash /home/user/architecture-pro-rag/update.sh
```
