В папке indexer\knowledge_index содержатся построенный индекс.
В файле vector_indexer.py скрипт индексатора.
Запускать так
``` python vector_indexer.py --csv_folder ./csv --output_path ./knowledge_index```
В файле bot.py скрипт бота для проверки результатов индексации.
На картинке Индексация.png демонстрация ответов бота из индекса.
